# 🎮 스트리머 파티 매칭 & 레디 체커 (Streamer Party Ready)

> 스트리머(방장)가 게임을 열고 방 코드를 공유하면, 시청자/참가자가 접속하여 **실시간으로 준비 완료(READY) 여부를 확인**할 수 있는 무설치 데스크톱 프로그램입니다.

---

## 🌟 핵심 특징

1. **무설치 & 무설정 실시간 연결**:
   - 포트포워딩, 외부 IP 노출, 회원가입이 **전혀 필요 없습니다**.
   - 공용 고속 클라우드 통신망(MQTT)을 이용해 방 코드 하나로 다른 집에 있는 사람끼리 즉시 연결됩니다.

2. **💾 입력값 자동 저장 (PC 영구 보관)**:
   - 방이름/게임명/컨텐츠명, 방장 닉네임, 방 코드, 참가자 닉네임, 공지사항 등이 실행 중인 PC의 AppData(`%APPDATA%/StreamerPartyReady/config.json`)에 자동 저장됩니다.
   - 프로그램을 껐다 켜도 이전에 입력했던 내용이 그대로 유지되어 매번 다시 입력할 필요가 없습니다.

3. **⚡ GitHub 기반 원클릭 자동 업데이트**:
   - 프로그램 실행 시 백그라운드에서 GitHub 최신 릴리즈를 자동으로 확인합니다.
   - 새로운 버전이 배포되면 **프로그램 오른쪽 하단에 초록색 [⚡ 새 버전 업데이트] 버튼**이 생성됩니다.
   - 버튼을 누르면 새 `.exe` 파일을 자동으로 다운로드하고, 기존 실행 파일을 교체한 뒤 프로그램을 무중단으로 재시작합니다.

4. **👑 방장(스트리머) 특화 기능**:
   - **기본 방장 닉네임**: `"용봉탕"` 기본 설정.
   - **방이름 / 게임명 / 컨텐츠명**: 변경 시 실시간 동기화 및 PC 자동 저장.
   - **실시간 준비 완료 현황판**: 참가자 명단 및 🟢 READY 상태 실시간 업데이트.
   - **참가자 전용 부드러운 효과음**: 삐빅 소리 대신 윈도우 정품 시스템 알림음 적용. 방장은 레디 소리에 방해받지 않도록 음소거되며, 참가자에게만 효과음이 들립니다.
   - **OBS / 방송용 Always-On-Top**: 게임 화면이나 OBS 위에 항상 띄워둘 수 있습니다.
   - **방 코드 원클릭 복사**: 채팅창이나 디스코드에 1초 만에 공유 가능.
   - **⚔️ 팀 나누기 (A팀/B팀)**: 내전 진행 시 참가자들을 공평하게 청팀/홍팀으로 자동 셔플!
   - **🎲 랜덤 추첨 (룰렛)**: 시참 참가자 중 무작위 1명 추첨!
   - **🔔 전체 레디 요청**: 미준비 참가자 화면에 "준비해 주세요!" 알림 발송.
   - **📢 실시간 공지 전송**: 참가자 화면 상단에 방장 공지사항 실시간 출력.

5. **🙋 참가자(시청자) 화면**:
   - 방장이 정한 게임명과 공지 실시간 확인.
   - 누르기 편한 초대형 **[⚡ 준비 완료 (READY)]** 토글 버튼 (누르면 부드러운 알림음 재생).
   - 현재 방에 들어온 다른 참가자 현황 실시간 확인.

## 🚀 사용 방법

### 방법 1: 독립 실행 파일 (`.exe`)로 실행 (가장 추천)
- **`dist\StreamerPartyReady.exe`** 파일을 더블 클릭하여 실행합니다.
- 방장과 참가자 모두 **동일한 `.exe` 파일**을 사용합니다!

#### [방장 진행 순서]
1. `StreamerPartyReady.exe` 실행 ➔ 좌측 **[👑 방장 모드]**
2. 방이름/게임명/컨텐츠명(기본: `오버워치 내전`)과 닉네임(기본: `용봉탕`), 방 코드를 확인 후 **[방 만들기]** 클릭
   *(이전에 입력한 내용은 PC에 자동 저장되어 있습니다)*
3. 생성된 **방 코드**를 복사하여 시청자 채팅창이나 디스코드에 안내!
4. 참가자가 들어와서 레디를 누르면 실시간으로 🟢 READY 상태가 뜹니다.

#### [참가자 진행 순서]
1. `StreamerPartyReady.exe` 실행 ➔ 우측 **[🙋 참가자 모드]**
2. 내 닉네임과 방장에게 받은 **방 코드** 입력 후 **[방 입장하기]** 클릭
3. 화면 중앙의 커다란 **`[⚡ 준비 완료 (READY)]`** 버튼 클릭!

## 🔄 GitHub 자동 업데이트 배포 방법

GitHub 저장소(`sandcat22/streamer_party_ready`)에 새로운 버전을 배포하는 방법입니다:

### 방법 A: GitHub Releases 이용 (표준)
1. GitHub 저장소의 **Releases** ➔ **Draft a new release** 생성
2. Tag 버전을 `v1.0.1` 형식으로 입력 (기존보다 높은 버전 번호)
3. 빌드된 새 `StreamerPartyReady.exe` 파일을 Release의 Attach binaries 영역에 업로드
4. Release를 Publish하면, 실행 중인 사용자들의 프로그램 우측 하단에 자동으로 업데이트 버튼이 표시됩니다!

### 방법 B: `version.json` 이용 (간편)
저장소 루트의 `version.json` 내용을 새 버전과 다운로드 링크로 수정 후 커밋 & 푸시:
```json
{
  "version": "1.0.1",
  "download_url": "https://github.com/sandcat22/streamer_party_ready/releases/download/v1.0.1/StreamerPartyReady.exe",
  "notes": "기능 추가 및 버그 패치"
}
```

## 📁 프로젝트 구조

```
streamer_party_ready/
├── network/
│   ├── __init__.py
│   ├── config_manager.py   # %APPDATA%/StreamerPartyReady/config.json 로컬 설정 영구 보관 모듈
│   ├── updater.py          # GitHub API 릴리즈 감지 및 무중단 자동 교체 업데이터
│   └── mqtt_manager.py     # 실시간 무설정 클라우드 브로커 네트워크 엔진
├── ui/
│   ├── __init__.py
│   ├── theme.py            # 다크 게이밍 테마 및 윈도우 네이티브 시스템 효과음
│   ├── welcome_screen.py   # 로비 화면 (입력값 자동 복원/저장, 업데이트 수동 확인)
│   ├── host_view.py        # 방장 대시보드 (현황판, 팀 나누기, 추첨, 공지 저장 등)
│   ├── participant_view.py # 참가자 화면 (대형 레디 버튼, 시스템 차임벨, 현황판)
│   └── main_window.py      # 메인 윈도우 컨트롤러 & 우측 하단 플로팅 업데이트 버튼
├── assets/
│   ├── icon.ico            # 프로그램 실행 아이콘
│   └── icon.png
├── main.py                 # 실행 진입점 (HiDPI 지원)
├── streamer_party_ready.spec # PyInstaller 빌드 스펙
├── build.py                # 안전한 파이썬 빌더
├── build_exe.bat           # 원클릭 배치 빌더
├── version.json            # GitHub 업데이트 메타데이터
├── requirements.txt        # 의존성 목록
└── README.md               # 사용 설명서
```
